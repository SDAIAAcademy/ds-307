# About `ossie-schema.json`

`ossie-schema.json` is the JSON Schema of the Apache Ossie core specification, version 0.3.0.dev0, copied unchanged
from <https://github.com/apache/ossie/blob/main/core-spec/ossie-schema.json> (commit 70c3c68, read on 15 November
2026) so that the labs can validate a semantic model without a network connection.

`OSSIE-LICENSE.txt` beside this file.

Version 0.3.0.dev0 is the in-development version of the specification: its schema can still change. Re-copy the file
when the course is refreshed, and read the project's change history before you do.
